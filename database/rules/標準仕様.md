| 項目 | 標準値 | 備考 |

## 2. 主回路構成（標準）

```
電源 → 主幹ブレーカ(MCCB) → 各分岐ブレーカ(MCCB/MCB)
    → 電磁開閉器(MSまたは電磁接触器+サーマルリレー)
    → モータ / インバータ / サーボドライバ
```

- インバータ使用時: 電磁開閉器ではなく **ブレーカ+電磁接触器**（インバータ内蔵の保護機能を利用）
- サーボ使用時: ブレーカ+電磁接触器（サーボドライバ内蔵の過負荷保護を利用）
- スターデルタ始動が必要な場合: Agent01が確認・フラグを立てる

## 6. 標準的な安全回路構成と安全レベルの決め方

### 6-1. 🚨 客先指定がない場合、最高レベル（PLe / Cat.4）にはしない

**既定値は「リスクアセスメントの算定値」であって「最高レベル」ではない。**
指定がないことは、最高レベルを求められていることを意味しない。

過剰なPLは規格違反ではないが、実務上の害がある。

| 過剰にした場合の害 | 内容 |
|---|---|
| **安全装置のバイパスを誘発** | 冗長・診断が増えるほど誤検出停止が増え、稼働率が落ちる。現場が安全装置を無効化する動機になり、**結果として実際の安全性が下がる**（最も重大な害） |
| コスト・納期 | 安全リレー上位機種・冗長化部品・検証工数が増える |
| 盤寸法 | 部品増で盤が大きくなる。「コンパクトに」という要望と競合する |
| 保守性 | 構成が複雑になり、現場で原因究明・復旧がしにくくなる |

**「PLを上げておけば安全」は誤り。** PLは制御系の信頼性の指標にすぎず、
本質的安全設計（開口寸法・速度・構造）を代替しない。手が届く構造のままPLeにしても
リスクはあまり下がらない（`規格.md §3-1` のリスク低減の優先順位）。

### 6-2. 安全レベルの相場観（社内の目安）

**リスクアセスメントの代替ではない。** 算定結果がこの表と大きく違う場合、
仮定か機械構造のどちらかを見直す手がかりとして使う。

| 設備・状況 | 一般的な水準 |
|---|---|
| **搬送コンベア・搬送機（人が手を入れる作業がある）** | **Cat.3 / PL d** ← 国内FAで最も一般的。当社の基準線 |
| コンベア（全面ガードで手が入らない。非常停止のみ） | Cat.1〜2 / PL b〜c（JIS B 9703 の非常停止は必須） |
| 産業用ロボットのセル（安全柵＋インターロック） | Cat.3 / PL d |
| 組立・検査装置（低速・軽量、手作業が多い） | Cat.2〜3 / PL c〜d |
| プレス・シャー・回転刃物・ロール機の噛み込み等、**接触＝即重大傷害で回避不能** | Cat.4 / PL e |
| 高速・重量物の可動部で人が挟まれると致命的 | Cat.4 / PL e |

> **PLe が妥当なのは限定的**（プレス・刃物・高速重量物等）。一般的な搬送設備で
> PLe を選ぶのは通常過剰であり、その場合はまず機械構造の見直しを検討する。

### 6-3. 算定がPLeになったときの手順

リスクグラフで PLe が出ても、**すぐ Cat.4 で設計しない。** 順序は以下。

1. **本質的安全設計を見直す**（`規格.md §3-1` の優先順位1）
   - 開口を手が入らない寸法にする（JIS B 9718）／搬送速度を下げる／
     作業を停止中に限定できる構造にする
   - これで S・F・P が変わり、多くの場合 **PLd に下がる**
2. それでも PLe が必要なら Cat.4 で設計する（プレス等はここに該当）
3. **仮定でPLeになっている場合は、上げる前に客先に実態を確認する。**
   1問確認すれば済むことに冗長化費用をかけない（曝露頻度・回避可能性の確認）

**迷ったら Cat.3 / PL d を基準線とし、そこから上げる／下げる理由を必ず記録する。**

### 6-4. 標準的な回路構成

| 項目 | 標準 | 備考 |
|---|---|---|
| 非常停止回路 | b接点（2b接点品）直列・**手動リセット** | JIS B 9703。CE不要の国内案件でも適用する |
| ドアインターロック | 安全ドアSW（予期しない起動を防ぐ場合は**ロック付き**） | JIS B 9716 |
| Cat.3 の主回路遮断 | **安全接触器2台直列＋ミラー接点フィードバック**（溶着検出） | 単一故障で停止機能を失わない＋故障検出 |
| 安全カテゴリ目標 | **Cat.3 / PL d を基準線**（6-2の相場観に従い上下させる） | **CE対応の有無に関わらず**、危険エリアへの立ち入りがあれば適用 |

## 7. 容量選定マージン（ブレーカ・電磁接触器）

- モータ負荷: **モータ定格電流の1.25倍以上** を選定基準に（カタログの選定表に従う）
- インバータ二次側: インバータ出力電流に対応したブレーカ・接触器を選定（カタログp参照）
- 余裕率は必ずカタログ記載の選定基準を優先し、本ファイルの値はあくまで目安

## 8. 納入範囲の標準

### 🚨 客先向け文書で「工事」という言葉を使わない

**建設業法・電気工事業法上、当社の役務が「工事」（建設工事・電気工事）と受け取られる
表現は法的に問題がある。** 質疑書・仕様書・見積書など**客先に出る文書では「工事」を使わない**。

| 使わない | 使う |
|---|---|
| 工事範囲 | 納入範囲 |
| 盤外配線工事 | 盤外配線 |
| 接地工事 | 接地極の敷設（当社範囲は盤の接地端子まで） |
| 据付工事 | 現地据付 |

例外: `database/rules/規格.md` の「接地工事」は電技解釈 第17条の**法令上の用語**なので
そのまま使う（規格名・条文の引用は変えない）。社内文書も混乱を避けるため
「納入範囲」で統一する（客先文書へ言葉が流れ込むのを防ぐ）。


**原則は「装置単体の制御盤」**。以下を範囲内・範囲外として扱う。
案件ごとに異なるため、Agent01が案件初期に必ず確認する。

| 区分 | 内容 |
|---|---|
| 範囲内（標準） | 制御盤の設計・製作、盤内配線、盤内機器の選定、盤面操作部品、盤側の接地端子 |
| 範囲外（明示的に含む場合のみ） | 盤外配線（盤〜モータ・センサ間）、受電設備・引込変圧器、接地極の敷設、現地据付・試運転 |

### 範囲外の項目を設計条件として客先に問わない

範囲外の項目は「客先確認」に積まない。積むと**答えようのない質問**になる。

| 項目 | 盤内のみの場合の扱い |
|---|---|
| 盤外の電線路長 | 対象外。**電圧降下計算そのものを行わない**（`電線選定.md §5`） |
| 引込変圧器容量・短絡容量 | 対象外。主幹ブレーカは汎用機種の標準遮断容量で選定する |
| 接地極の敷設・接地抵抗値 | 対象外。盤側は接地端子を用意し、種別（D種等）の指定有無のみ確認する |
| モータ銘板の実測値 | 客先に問わない。**モータの型式・メーカーが分かればメーカー公表値**、不明ならJEM1135参考値で選定し、最終は現物確認（区分「現地調査」） |

> 盤外配線・受電設備・接地極の敷設が納入範囲に含まれる場合は、上記を通常どおり確認する。
> 「含まれるかどうか」を先に確定させることが順序として先。
