## 0. 安全対策の範囲分担（🚨 メカ設計に踏み込まない）

> `spec_summary.md` の「納入範囲」を確認してから書く。**盤内のみの案件では、下表の
> 「装置側」は当社の成果物ではない。**「ガードを設けます」と書くとやらないことを
> 約束することになる（`database/rules/標準仕様.md §8`）。

| 安全対策 | 当社（制御盤） | 装置側（メカ設計・客先または装置メーカー） |
|---|---|---|
| 非常停止 | 回路・盤面の押しボタン | 現場操作盤の設置位置 |
| ガード・安全柵・扉・カバー | — | 設計・製作すべて |
| 安全スイッチ・光線式安全装置 | 型式候補の提示・盤側の接続端子・安全回路 | 取り付け・位置決め・安全距離（JIS B 9715・9718） |
| モータの停止 | 安全接触器・安全リレー・冗長化 | — |
| 本質的安全設計（開口寸法・速度・構造） | — | すべて（当社は提案するだけ） |

**リスクアセスメントの主体は機械の製造者**（装置メーカー・客先）。本書は
**制御盤の範囲で何を実現するかの提案**であり、装置全体の安全を保証するものではない。

装置側の対応がなければ制御盤側だけでは安全機能が成立しない場合がある
（例: 扉が無ければロック付き安全スイッチを取り付けられない）。
**客先への承認依頼で装置側の対応予定を必ず確認する。**

| No | 安全機能 | 危険事象 | S(重篤度) | F(頻度) | P(回避可能性) | 推定PL | 設計者確認 |
|---|---|---|---|---|---|---|---|

**パラメータの定義（ISO 13849-1）**
- S1: 軽傷（回復可能）/ S2: 重傷・死亡（回復不可）
- F1: まれ〜あまり頻繁でない / F2: 頻繁〜連続

## 6. 客先への承認依頼（客先送付用ドラフト）

> **「安全カテゴリ・PLの指定はありますか」ではなく「この安全レベルで設計します。
> よろしいですか」を送る。** 客先がPL/SIL値を最初から持っていることは稀なので、
> 当社が算定した内容を提示して承認を得る（`agents/04_安全設計/AGENT.md` フェーズ5）。

弊社にて、下記のとおり安全対策を検討いたしましたのでご確認をお願いいたします。

| 項目 | 内容 |
|---|---|
| 想定した作業・危険源 | （客先からのヒアリング内容を平易に記述） |
| 安全対策の概要 | （例: 非常停止＋光線式安全装置による停止。専門用語を避けて記述） |
| 安全レベル（社内参考） | Cat. ／ PL（客先には必要な場合のみ提示） |
| **弊社の範囲 / 装置側のご対応** | （§0の範囲分担を客先向けの言葉で。**装置側の対応が前提であることを明記する**） |

| No | 確認事項 | 回答欄 |
|---|---|---|
| 1 | 上記の内容で相違ないでしょうか。 | 承認する / 修正を希望する（内容:　） |
| 2 | ガード・柵・扉は装置側でご対応いただけますでしょうか。 | 対応する / 対応しない / 装置メーカーに確認する |
| 3 | 安全機器の装置への取り付けはどちらでご対応されますか。 | 装置メーカー / 貴社 / 別途相談 |
| 4 | 設備全体のリスクアセスメントを実施済みでしたら結果をご提供ください。 | |
| 5 | 想定していない使用方法・作業がありましたらお知らせください。 | |
