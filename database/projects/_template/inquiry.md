## このファイルと Excel の関係

**質疑事項の正本はこのMarkdownである。** 質問の追加・削除・文言修正はここで行う。

> 🚨 **本書は客先に出る文書。「工事」という言葉を使わない**（建設業法・電気工事業法上、
> 当社の役務が「工事」と受け取られる表現は法的に問題がある）。
> 「工事範囲」→**「納入範囲」**、「盤外配線工事」→「盤外配線」、
> 「接地工事」→「接地極の敷設」。詳細は `database/rules/標準仕様.md §8`。

```
_template/inquiry.md ──コピー──▶ {案件ID}/inquiry.md ──変換──▶ inquiry_{案件ID}.xlsx
   （ひな形・36問）     Agent01が案件用に調整  ▲  generate_inquiry.py   │ 客先へ送付
                                            └──────────────────────┘
                                              import_inquiry.py
                                              （回答が記入された返送Excelを取り込む）
```

```
pip install openpyxl        # 初回のみ
python scripts/generate_inquiry.py {案件ID}                    # 送付用Excelを作る
python scripts/import_inquiry.py {案件ID} <返送されたxlsx>      # 回答を取り込む
```

回答の取り込みは `--dry-run` で内容を確認してから実行するとよい。
Excelが空欄の質問と、Markdown側に既に回答がある質問は書き換えない（`--overwrite` で上書き）。
**回答を蓄積するのはMarkdown側**。Excelに直接書いた内容は再生成で消える。

- `{案件ID}/inquiry.md` があればそれを読む。無ければこのひな形を読む
- 出力先は案件フォルダ（フォルダが無ければカレント）。`--source <path.md>` で読込元を直接指定できる
- `scripts/generate_inquiry.py` は変換器であり質問を持たない。**スクリプト側に質問を書かない**
  （以前は同じ質問定義がMarkdownとPythonの両方にあり、片方だけ直すとずれていた）

案件用にコピーした後は、**既に確定している項目を個別質問から外し**、前提確認の1問に
まとめてよい（例: `20260614-001/inquiry.md`）。36問を全部送る必要はない。

### 変換時の扱い

| Markdown | Excel |
|---|---|
| `## ヘッダー` の表 | 上部のヘッダー欄（宛先・設備名称・件名・送付日・回答期限・送付者・連絡先の順） |
| `### 【節名】` | 節見出し行（`■ 節名`） |
| `\| Q1 \| 確認事項 \| 回答欄 \| 備考 \|` | 質問1行。No列が `Q数字` の行だけを拾う |
| 回答欄に記入済みの内容 | そのまま転記（未記入欄のみ水色になる） |
| `{客先名}` 等のプレースホルダ | 残したまま水色表示（手入力箇所の目印）。`{project_id}` と送付日のみ自動で埋まる |
| 「## 質疑事項」の外にある表・本文 | 無視される |
