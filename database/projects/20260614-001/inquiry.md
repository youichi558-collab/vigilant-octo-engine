## 回答受領後の対応（2026-07-30 受領）

回答は2種類あった。**設計条件として使える回答**と、**質問自体が成立していないという指摘**。

### 設計条件として反映したもの

| 質疑 | 回答 | 反映先 |
|---|---|---|
| Q1 | 相違なし | 電気条件No.1/3/4/6・安全条件（CE不要）を「確定」で維持 |
| Q6 | 暫定3分に1回（約20回/h）。製品ロット未定・受注がなければ動かない | 電気条件No.7。20回/h は AC-3 の範囲。**AC-4（寸動・反転頻繁）は不要**と判断 |
| Q7 | 屋内・装置付近・油無・**結露不明** | 機械条件。結露は未決に残す（不明なら盤内ヒータ・サーモの要否が決まらない） |
| Q8 | 制約なし。なるべくコンパクトに | 機械条件（盤サイズ設計方針） |
| Q9 | 非常停止**必要** | 安全条件 |
| Q10 | 危険エリアに手を入れる作業**あり** | 安全条件。**Agent04（安全設計）の起動が必要になった** |
| Q11 | 配線色・電線種別の指定なし | 社内標準（方式A）を適用 |
| Q12 | 部品メーカー指定なし | 標準仕様の優先順位で選定 |
| Q13 | 客先仕様書・既設図面なし | 参考資料なしを確定 |

### 質問が成立していなかったもの（ひな形・ルール側を修正した）

いずれも**納入範囲が「装置単体の制御盤（盤内）」である**という前提が、質問側に無かったことが原因。

| 質疑 | 指摘 | 対処 |
|---|---|---|
| Q2 モーター銘板の全負荷電流 | 銘板値が最初から分かっていることはあり得ない | 客先に聞く項目ではない。**モーターの型式・メーカー**を聞く形に変更し、電流値はメーカー公表値／JEM1135参考値で選定する。銘板は現地・現物確認（区分「現地調査」） |
| Q3 引込変圧器容量・短絡容量 | 装置単体では引込側容量を考えない | 受電設備が納入範囲に含まれる場合のみ聞く条件付き質問に変更 |
| Q4 接地の種別・工事方法 | 接地極の敷設方法は考えない | 盤側の**接地端子の要否・種別指定**のみを聞く形に変更。接地極の敷設は納入範囲外 |
| Q5 盤〜モーターの電線路長 | 盤外・納入範囲対象外 | 盤外配線が納入範囲に含まれる場合のみ聞く条件付き質問に変更。**含まれない場合は電圧降下計算そのものが対象外** |

反映先:

- `database/rules/標準仕様.md` に「納入範囲の標準」を追加（原則は盤内。盤外配線・受電設備・
  接地極の敷設・現地据付は明示的に含む場合のみ）
- `database/rules/電線選定.md`: 線路長不明時は「ユーザーに確認」から
  「納入範囲に盤外配線が含まれるかを先に確認し、含まれなければ電圧降下計算の対象外」に変更
- `_template/inquiry.md`: **納入範囲を最初に聞く質問を追加**し、上記4問を修正（36問）
- `agents/01_仕様解析/AGENT.md`: 案件初期必須確認項目に「納入範囲」を追加
- `agents/03_部品選定/AGENT.md`: 線路長の扱いを納入範囲に従って判断するよう変更
